Brain Technologies

2019-2020

I was a prototyper at Brain Technologies, working on interaction architecture and designing humane interfaces for new types of computer experiences. Some of my projects included:

  • Natural language-based generative UI — interfaces that composed themselves in response to what users said
  • Ways for users to understand and steer model behavior
  • NLP feedback loops that helped the system learn from user intent over time

All of this predated the era of large language models. For more information, please contact me directly.
